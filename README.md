# 🏠 찌니 대시보드

찌니의 하루를 포근하게 기록하는 모바일 우선 웹 앱입니다.
할 일 · 별 · 도장판 · 등교·학원 준비 · 엄마 일정 · 독서 기록 · 학교/학원 일정 · 보상 트래커를 한 화면에서 볼 수 있어요.
찌니 한 명 전용이라 카드·탭·시간표가 모두 찌니 기준으로 그려집니다.

- **바로 열기**: `index.html` 더블클릭 (인터넷이 없어도 화면은 열립니다)
- **휴대폰에 설치**: 아래 "홈 화면에 추가" 참고
- **필요한 것**: 없음 (외부 라이브러리 0개, 날씨만 Open-Meteo 무료 API)
- **잠금**: 앱을 열면 4자리 비밀번호를 먼저 물어봅니다 (한 번 맞추면 그 기기에서는 계속 열려요)

## 1. 무엇이 들어 있나요

| 섹션 | 설명 |
| --- | --- |
| 🏠 헤더 | 오늘 날짜(자동), "오늘도 함께 기록해요", 🔊 효과음, ⚙️ 설정, ↗ 공유 |
| 🔒 잠금 화면 | 4자리 비밀번호(PIN) 키패드. 맞히면 이 기기에 열림 상태 저장, 설정에서 다시 잠그기 |
| ☀️ 날씨·미세먼지 | Open-Meteo 실시간 날씨 + 미세먼지/초미세먼지 등급과 "마스크 챙겨요" 같은 한 줄 안내. 카드를 누르면 새로고침 |
| 🏫 오늘의 학교·학원 일정 | 오늘 요일에 맞는 찌니의 하교 시간과 학원 시간, "지금 ○○ 중 / 다음 ○○" 표시. 주말에는 주말 인사 + 주간 시간표 버튼 |
| 🎒 등교·학원 준비 | 평일 **08:30 등교 출발**까지 남은 시간과 준비물(안경·외투·핸드폰) 체크, 학원은 **수업 10분 전 출발**까지 남은 시간과 수업별 확인(줄넘기·검도=외투 / 영어=영어학원 가방 / 재능=과제) 체크 |
| 🎤 엄마 일정 | 오늘의 일정과 다가오는 일정(최대 6개). 화면에서 직접 추가·수정·삭제하고, 처음 열 때는 11월 일정(11/23~11/30)이 들어 있어요 |
| 🐹 찌니 카드 | 찌니 캐릭터, 이름, 별 개수, 돼지저금통(누르면 별 조정) |
| ✅ 오늘 할 일 | 찌니 체크리스트. 체크하면 ⭐ 1개, ✏️ 고치기, ✕ 지우기(되돌리기 가능), 반복은 **오늘만 / 매일 / 평일(월~금)** |
| 🎁 찌니 보상 트래커 | 문제집·재능학습지 완료에 따른 오늘의 보상 해금 여부 + 주5일 완주 진행률(주말 닌텐도 +30분) |
| 🐹 도장판 | 월~일 도장, 🔥 연속 일수, 이번 달 개수, 달력 보기 (구성원이 한 명이라 탭 없이 보여요) |
| 📚 독서 기록 | 읽은 날·책 제목·짧은 감상평을 남기고 목록으로 모아 보기. 고치기·지우기(되돌리기) 지원 |
| 🔊 효과음 | 체크하면 짧은 '띵', 준비·할 일 카드를 다 마쳤거나 보상이 열리거나 도장을 찍으면 팡파레와 박수 소리. 헤더의 🔊/🔇 또는 설정에서 끄고 켜기 (기본 켜짐, 이 기기에 저장) |

기록은 모두 이 기기의 브라우저 저장소(localStorage)에 저장돼요. 새로고침해도 그대로 남습니다.

## 2. 실행 & 배포

### 그냥 열기
`family-dashboard/index.html` 파일을 브라우저로 열면 바로 동작합니다.
(날씨는 인터넷이 필요하고, 안 되면 "날씨 정보 없음"으로 표시돼요.)

### 로컬 서버로 열기 (권장)
```bash
cd family-dashboard
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
로컬 서버나 https 주소에서 열면 서비스 워커가 등록되어 **오프라인에서도** 열립니다.

### 무료 호스팅
- **GitHub Pages**: 저장소에 `family-dashboard/` 폴더를 올리고 Settings → Pages 에서 폴더를 지정
- **Vercel / Netlify**: 폴더를 그대로 드래그해서 배포 (빌드 설정 없음, 정적 파일)

### 홈 화면에 추가
- **아이폰(사파리)**: 공유 → 홈 화면에 추가
- **안드로이드(크롬)**: 우측 상단 ⋮ → 앱 설치 / 홈 화면에 추가

`manifest.json` + 앱 메타 태그 + 아이콘이 준비되어 있어서 아이콘이 있는 앱처럼 설치됩니다.

```
│   └── sync-supabase.example.js  여러 기기 동기화 예시 (기본 미사용)
├── assets/fonts/              나눔스퀘어라운드 + Gmarket Sans (앱에 포함)
├── icons/                     앱 아이콘 (192/512/maskable/apple-touch)
│   └── _source.html           아이콘을 다시 만들 때 쓰는 원본 화면
└── preview-*.png              미리보기 스크린샷
```

## 4. 자주 고치는 곳

### 학기 시간표 바꾸기 — `js/schedule.js`
```js
jjini: {
  days: {
    1: { school: '13:40', items: [ { name: '영어', start: '16:20', end: '17:30' } ] },
    2: { school: '13:40', items: [ { name: '검도', start: '16:30', end: '17:30' },
                                    { name: '줄넘기', start: '18:20', end: '19:20' } ] },
    // 1=월 … 5=금
  }
}
```
`name` 은 `영어 / 댄스 / 줄넘기 / 검도 / 재능` 중 하나면 자동으로 색이 붙고,
새 이름을 쓰면 `colors` 에 한 줄 추가하면 됩니다.

### 파일을 고친 뒤 (중요)
앱을 이미 홈 화면에 추가해 쓰고 있다면, `sw.js` 안의 `CACHE = 'family-dashboard-v5'` 을
`v6`, `v7` 처럼 올려 주세요. 그래야 휴대폰이 예전 파일 대신 새 파일을 받아옵니다.

### 기본 할 일(루틴) 바꾸기
앱 안에서 직접 하면 됩니다. `+ 할 일 추가` → 반복에서 **매일** 또는 **평일(월~금)** 선택.
- **매일** 루틴은 주말에도 나옵니다. (예: 재능학습지 국어·수학 2장씩)
- **평일** 루틴은 토·일에는 자동으로 쉬고 월요일에 다시 나타납니다. (예: 한자어휘·역사 문제집 2장씩)

처음 상태를 바꾸고 싶으면 `js/store.js` 의 `defaultState()` 안 `routines` 를 고치세요.
(이미 저장된 기록이 있는 브라우저에는 적용되지 않아요. 설정 → 모든 기록 지우기 후 새로 시작하면 반영됩니다.)

### 찌니 이름·동네 바꾸기
헤더 ⚙️ 설정에서 이름/한 줄 소개를 고치고, 동네는 목록에서 고르거나 검색해서 선택합니다.
(검색은 Open-Meteo 지오코딩을 사용해요.)

### 비밀번호 바꾸기
`js/lock.js` 의 `PIN_SHA256` 값을 바꾸면 됩니다. 새 비밀번호는
`sha256('jjini-dashboard:' + 4자리)` 해시로 넣어 주세요(비밀번호를 코드에 그대로 두지 않기 위한 장치).

## 5. 찌니 보상 규칙 (앱에 구현된 그대로)

| 보상 | 조건 | 표시 |
| --- | --- | --- |
| 📺 영상 30분 | 그날의 **문제집**(한자어휘 · 역사 2장씩)을 모두 완료 | 두 개 다 체크되면 초록색 "해금! 🎉" |
| 💻 노트북(엔트리코딩) 30분 | 그날의 **재능학습지**(국어 · 수학 2장씩)를 모두 완료 | 위와 동일 |
| 🎮 주말 닌텐도 +30분 | **월~금 5일 모두** 문제집을 완료 | 진행 막대 5칸 + "토·일 각 4시간 → 4시간 30분" |

- 평일에는 문제집 2개, 주말에는 문제집이 없는 날이라 두 보상 중 문제집 쪽은 "쉬는 날"로 표시됩니다.
- 주말 닌텐도 시간은 완주 시 **토·일 모두 4시간 30분**으로 표시됩니다.
- 보상 조건은 할 일의 `group` 값(`workbook` / `jaeneung`)으로 계산돼요.

## 6. 데이터 · 동기화

- 저장 위치: `localStorage` 키 `uri-family-dashboard.v3`
- 구조: `settings` (동네), `members` (이름·별), `routines` (반복 할 일), `days` (날짜별 할 일·완료), `stamps` (도장)
- 준비 체크: `localStorage` 키 `jjini.prep.v1` 에 날짜별로 저장 (등교 준비물 · 학원 수업별 확인)
- 일정: `localStorage` 키 `jjini.lectures.v1` (처음 열 때 11월 일정 기본값 채움)
- 독서 기록: `localStorage` 키 `jjini.books.v1`
- 초기화: 설정 → **모든 기록 지우기**
- 여러 기기에서 함께 쓰려면: `js/store.js` 의 `FamilyStore.setAdapter()` 에 Supabase/Firebase 어댑터를 끼우면 됩니다.
  `js/sync-supabase.example.js` 에 표(table) 만들기 SQL까지 예시로 넣어 두었습니다.

### 날짜·시각 미리보기 (테스트용)
주소 뒤에 `?today=2026-11-24` 처럼 날짜를 붙이면 그날 화면으로 열립니다.
`?now=08:10` 을 함께 붙이면 그 시각 기준으로 등교·학원 준비 남은 시간을 확인할 수 있어요.
(기록은 그대로 유지되고, 그 날짜의 할 일·일정·보상 상태를 확인할 수 있어요.)
